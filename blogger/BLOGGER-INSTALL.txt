WEB2APK INSTALL

1. Upload Web2APK-Blogger-Automatic-Theme-v2.xml in Blogger -> Theme -> Restore/Upload, or open Edit HTML and paste the XML.
2. Cloudflare Worker API: https://web2apk.traderwithsbt.workers.dev
3. In Cloudflare Worker settings configure:
   - GITHUB_TOKEN = Secret (GitHub fine-grained token with Actions Read/Write and Contents Read/Write)
   - GITHUB_REPO = traderwithsbt-ipg/web2apk
   - GITHUB_REF = main
4. The GitHub repository must contain .github/workflows/build-web2apk.yml and backend/.
5. The Blogger page sends the selected icon/splash automatically to the Worker; the Worker commits them temporarily to the repo, the GitHub Action builds the APK, creates a Release, then cleans the temporary images.
6. Do not put the GitHub token in Blogger HTML/JavaScript.
